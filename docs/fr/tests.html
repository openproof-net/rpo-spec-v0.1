03 · CE QUE LE CONTRÔLE ÉTABLIT

L’INTÉGRITÉ EST UNE QUESTION DIFFÉRENTE DE LA VÉRITÉ.

Ce contrôle peut établir

  • que le texte est un JSON lisible ;
  • que les sections fondamentales du RPO sont présentes ;
  • l’empreinte exacte de la copie fournie ;
  • si cette copie est identique à la référence chargée.

Ce contrôle ne peut pas établir

  • que les déclarations contenues sont vraies ;
  • que les pièces sources sont authentiques hors du RPO ;
  • qui est juridiquement responsable ;
  • qu’une conclusion humaine ou juridique est correcte.

Une vérification RPO complète pourra aussi inclure le schéma JSON, les signatures, les empreintes des pièces et la confirmation d’une entrée de registre. Cette page montre volontairement le mécanisme le plus simple : une copie identique produit la même empreinte ; une copie modifiée en produit une autre.
